# Yadvendra Wagh — Data Engineer Portfolio

A custom-designed, modern, and high-performance portfolio website built from scratch for **Yadvendra Wagh (Data Engineer • 2+ Years Experience)**.

The website features an uncluttered editorial aesthetic, a responsive framed hero layout, interactive generative background physics, and a focused presentation of distributed data systems, verified certifications, and production projects.

---

## ✨ Features & Architecture

### 1. Interactive Generative Background
- **Physics Particle & Constellation Mesh:** GPU-accelerated HTML5 canvas animation with floating particles that organically connect and dynamically repel/attract based on mouse or touch coordinates.
- **Spotlight Aura:** A smooth radial ember gradient that glides with cursor movement using linear interpolation (lerp) inertia.

### 2. Framed Hero Card
- **Prominent Name Display:** Clean, bold typography ensuring 100% legibility across all screen sizes without awkward cropping or masking.
- **Custom Framed Portrait:** High-resolution portrait framed with dark glass borders, subtle shadows, and a floating 3x Certified credential badge.
- **Status Indicator:** Glowing emerald badge indicating real-time availability for data engineering roles.
- **Quick Actions:** One-click email copy button with animated toast feedback, direct resume link, and social channels.

### 3. Modern Data Engineering Focus
- **Distributed Computing:** Apache Spark, PySpark, and Spark SQL.
- **Lakehouse & Storage Architecture:** Databricks (Delta Lake, Delta Live Tables, Unity Catalog), Snowflake, and Data Warehousing.
- **Orchestration & Streaming:** Apache Airflow, dbt, Apache Kafka.
- **Cloud Infrastructure:** AWS (S3, Glue, Redshift), GCP (BigQuery, Dataflow), Docker, Kubernetes, Jenkins CI/CD.

### 4. Verified Certifications
Dedicated credential cards detailing core competencies:
1. **Databricks Certified Data Engineer Associate**
2. **Google Cloud Professional Data Engineer**
3. **Claude Certified Architect — Professional**

### 5. Interactive Project Showcase
- Clean editorial list with project categories, tech badges, and animated link indicators.
- **Floating Hover Preview:** Smooth cursor-following screenshot preview when hovering over any project on desktop.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic, accessible markup.
- **CSS3:** Custom design tokens, glassmorphism (`backdrop-filter`), responsive clamp typography, and mobile-first media queries.
- **Vanilla JavaScript:** 60fps canvas animation, clipboard API, and floating thumbnail previews with zero external dependencies.
- **Typography:** `Manrope` (display & body) and `JetBrains Mono` (technical tags).
